Časté otázky

Kolik web stojí?

Nový web stojí od 3 900 Kč jednorázově, nejsem plátce DPH. Přesnou cenu napíšu, až budu znát rozsah, takže před začátkem práce víte, kolik zaplatíte.

Jak dlouho trvá, než bude web hotový?

Záleží na rozsahu. Termín domluvíme před začátkem prací, abyste věděli, kdy web dostanete.

Opravdu mluvím přímo s vámi?

Ano. Web dělám sám. Píšete mně, odpovídám vám já a ozvu se vám do druhého dne.

Zvládnete i web, který už mám?

Ano. Můžu upravit texty, strukturu nebo technické nastavení stávajícího webu, pokud to dává smysl.

Pomůžete, aby mě našli na Googlu?

Připravím technický a obsahový základ pro vyhledávání. Pozice na Googlu ale nelze předem zaručit a výsledky se projevují za týdny až měsíce.

Je v ceně hosting a doména?

Doménu i hosting vám pomůžu zařídit. Co v ceně je a co se platí zvlášť, uvidíte předem v nabídce.

Budu si moct web sám upravovat?

Domluvíme se podle toho, co potřebujete. Často stačí, že změny provedu já podle vašeho e-mailu.
